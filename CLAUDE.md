# «Искажение» — Roblox-игра

Отдельный проект владельца, не связан с «офисом агентов». Работаем в ветке `roblox-game`.

## Общение
- Владелец — новичок в Roblox. Пиши по-русски, коротко и просто, без лишних терминов.

## Что за игра
Кооперативный шутер (1–4 друга, без PvP) с сюжетом по главам: команда героев («как Мстители»)
зачищает мир-симуляцию («как Матрица») от вируса. Чужие бренды и имена не используем.
- Дизайн: `docs/GDD.md` (там же план по неделям)
- Исследование рынка: `docs/research.md`
- Как запускать и публиковать: `README.md`

## Устройство кода
- Два места: Штаб (`lobby.project.json`) и Миссия (`mission.project.json`), общий код в `src/shared`, `src/server/common`, `src/client/common`.
- Сохранение: ProfileStore (`src/server/common/Packages`, сторонний код — не править).
- Настройки миссии передаются через MemoryStore (`MissionStore`), не через TeleportData.
- Вся экономика и урон — только на сервере; RemoteEvent проверяют входные данные.
- UI собирается кодом (`src/client/common/UI.luau`), карты пока тоже кодом (`LobbyMap`, `MissionMap`).

## Как работать
- Код пишем в файлах, в Studio его переносит Rojo. Скрипты прямо в Studio не правим — Rojo их перезапишет.
- Roblox Studio подключена через MCP: используй её, чтобы запускать тест (Play), читать Output,
  делать скриншоты и проверять изменения.
- Перенос между Штабом и Миссией работает только в опубликованной игре; в Studio тестируем места по отдельности.

## Инструменты на компьютере владельца
- Rojo 7.7.1: `C:\Users\artem\.local\bin\rojo.exe` (в PATH). Плагин Rojo — `%LOCALAPPDATA%\Roblox\Plugins\Rojo.rbxm`
  (`rojo plugin install` не находит Studio в реестре, поэтому плагин положен вручную).
- Запуск: в папке проекта `rojo serve lobby.project.json` (или `mission.project.json`), в Studio — новый Baseplate →
  Plugins → Rojo → Connect (порт 34872).
- MCP может видеть несколько окон Studio с одинаковым именем (`list_roblox_studios`): выбирай то, где есть
  `ServerScriptService.Lobby`/`Mission`.
- Ошибки `[Roblox] CorePackages ...` в Output — сбои встроенного UI Roblox, не наш код.

## Где остановились
Готовы недели 1–2: Штаб с порталами отряда, перенос на закрытый сервер миссии, сохранение,
временная миссия «закрыть три сбоя» → награда → возврат в Штаб.
Проверено в Studio (2026-10-25): Штаб и Миссия запускаются без ошибок, миссия проходится до награды.
Rojo установлен и подключён. Перенос между местами, сохранение и игра вдвоём в Studio не проверяются —
только после публикации.
Недели 3–4 (стрельба) сделаны и проверены в Studio (2026-10-26): оружие в `src/shared/Weapons.luau`,
сервер — `src/server/mission/WeaponService.luau` (сервер сам пускает луч и считает урон; попадают только
модели с тегом "Enemy"), клиент — `src/client/mission/Weapons.client.luau` и `Hud.luau`,
временные мишени убраны (их заменили враги). Пока нет: кнопки огня для телефона, моделей оружия, звуков.
Платные бусты (Game Pass, 2026-10-26): «Ускорение» (x1.5 бег + двойной прыжок) и «Взгляд сквозь код»
(подсветка врагов сквозь стены). Список — `Config.GamePasses` (Id = 0 до создания в Creator Hub),
сервер — `src/server/common/PassService.luau` (ставит игроку атрибуты `Pass_<Key>`), клиент —
`src/client/common/Boosts.client.luau` и `Shop.client.luau`. Проверено в Studio в Миссии; в Штабе — нет.
Решение владельца: вместо пушек герои дерутся силами (энергия вместо патронов) — переделка ещё впереди;
приоритет — то, за что игроки будут платить (бусты, «читы симуляции»).
Разовые бусты (Developer Product, проверены в Studio): «Бессмертие» 15 с, «Двойной урон» 30 с, «Встать сразу».
Список — `Config.Products`; приём чеков — `src/server/common/ProductService.luau` (номер чека пишется в
`Purchases` сохранения, чтобы не выдать дважды; в Штабе чеки не выдаются и ждут Миссию); действие —
`src/server/mission/BoostEffects.luau`. В Миссии возрождение 10 с (`Config.MissionRespawnTime`).
Владелец хочет бусты, «за которые реально платят». Добавлены (проверены в Studio в Миссии, один игрок):
разовые «Код уничтожения» (стирает врагов в радиусе 80), «x2 урон всему отряду» 60 с, «Бессмертие всему
отряду» 15 с — все видят сообщение, кто купил; навсегда «Дрон-помощник» (`src/server/mission/DroneService.luau`,
сам стреляет по врагам) и «VIP» (x2 биты, значок над головой, неоновый след, [VIP] в чате).
Не проверено: Штаб, игра вдвоём, значок VIP глазами (скриншот MCP не показывает подписи над головами).
Ещё не сделано из идей: стартовый набор за 49 R$ для новичков.

Графика (2026-10-26): свет и атмосфера — в `*.project.json` → `Lighting` (Future, ночь в Миссии, сумерки
в Штабе); свет Штаба не проверен. Враги (`src/server/mission/EnemyService.luau`): Пиксель, Блок (удар по
площади с предупреждением), Стрелок (медленные снаряды); бегут к игроку напрямую, без обхода препятствий.
Режим «Выживание» = глава Id 100 (`Kind = "Survival"`) в `Config.Chapters`, волны — в `MissionService`,
рекорд — `BestWave` в сохранении. Тест в Studio: атрибут `TestChapter` = 100 у ServerScriptService.
Проверено в Studio с одним игроком. Решение владельца по городу: основа кодом + почищенные готовые
модели (без чужих скриптов и лишних деталей).
Карта «Город» (`MissionMap.luau`, кодом): площадь с укрытиями в центре, 8 кварталов, улицы с фонарями,
стена из домов по краю, 3 сбоя с лучами, 8 точек появления врагов. Враги парят (HipHeight 1.5), чтобы
перебираться через бордюры, и обходят дома через PathfindingService. Готовые модели ещё не добавлены.

Двойники (`src/server/mission/DoppelgangerService.luau`, проверено в Studio): копия персонажа одного из
игроков (Clone без скриптов, свои анимации ходьбы), ходит с отрядом, через 25–45 с предаёт — взрыв,
Пиксели, в Главе 1 снова открывает закрытый сбой. Бесплатные подсказки: мерцает, сбивает буквы в нике,
враги его не трогают, после потери 40% здоровья раскрывается (до этого нет отметки попадания).
«Взгляд сквозь код», дрон и «Код уничтожения» нераскрытого двойника не выдают. Продаются «Сканер вируса»
(Game Pass, подсветка) и «Скан для всего отряда» (разовый). Тест: атрибут `TestDoubleDelay`.

Параллельные миры и машины — утверждены, план в `docs/GDD.md` (раздел 14а), улучшаем по ходу.
Сделан шаг 1: Транспортник (`src/server/common/VehicleService.luau`) — парит над землёй (сервер держит
высоту лучом вниз, газ/руль из VehicleSeat, LinearVelocity + AlignOrientation, физику считает сервер),
4 места, пустой исчезает через минуту. В Штабе — трасса вокруг площадки и «Гараж» (`src/server/lobby/Garage.luau`),
пока бесплатно для всех. Проверено в Studio одним игроком; свет Штаба подправлен и проверен.
Машины (2026-10-26): 5 штук — Глитч-байк, Вольт (электрородстер), Призма (гиперкар), Орбита (купе по мотивам
«машины из фильма», свой дизайн), Транспортник. Кузова сгенерированы в Studio (generate_mesh) и лежат ассетами
в инвентаре владельца — номера в `Config.Vehicles[…].ShellAsset`; сервер грузит их InsertService:LoadAsset
при старте (`VehicleDesigns.loadShells`), без кузова машина собирается из деталей (`VehicleDesigns.luau`).
Если игру будет публиковать группа, ассеты должны принадлежать ей. Седоков в детальном кузове прячем.
Автосалон в Штабе: подиумы с вращающимися витринами (вращение на клиенте), E — вызвать машину на трассу.
Реактивный прыжок с сальто (Shift/F, на телефоне кнопка) — Game Pass «Реактивные сопла»; над стенами трассы
невидимая преграда. Чужие бренды (Tesla, Audi) не используем — только «по мотивам».
Режим «Побег» (глава Id 200, `Kind = "Escape"`, проверен в Studio одним игроком): трасса 2400 студов
(`src/server/mission/EscapeMap.luau`), отряд по 4 в Транспортнике (`Config.Escape`), стена вируса догоняет
и ускоряется, погибшие возрождаются в машине, Стрелки у обочин, финиш — награда x1.2. В режиме Побег город
не строится. Тест: `TestChapter` = 200.
