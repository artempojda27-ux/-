# Магазин: что создать в Creator Hub

Здесь всё, что продаётся в «Искажении», готовым списком: название, описание, цена. Копируй как есть.
Когда создашь — пришли номер (ID) каждого, я впишу в `src/shared/Config.luau` и кнопки «купить» заработают.

Где создавать: **create.roblox.com → Creations → «Искажение» → Monetization**
- **Passes** (пропуски, покупаются один раз навсегда) — разделы 1 и 2
- **Developer Products** (разовые, покупаются сколько угодно) — раздел 3

У каждого пропуска нужна картинка 512×512 — можно пока любую, позже сделаем красивые иконки.

## Что прислать мне

Просто список «номер из таблицы — ID», например:
```
1 — 123456789
2 — 987654321
...
```
ID видно в Creator Hub на странице каждого пропуска или покупки (длинное число).

## Потом — ещё идеи на продажу (из плана)

- **Стартовый набор новичка** — 49 R$: скин Охотника + Ускорение + 500 бит, только в первые 3 дня
- **Машины за Robux** — сейчас все машины бесплатные; можно сделать 2–3 базовые бесплатными, а суперкары платными
- **Сезонный пропуск** — награды за задания сезона
