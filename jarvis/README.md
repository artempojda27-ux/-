# Джарвис: ИИ, который звонит тебе утром

Каждый будний день утром Джарвис звонит на твой телефон. Как это выглядит:

> «Доброе утро, босс. Джарвис на связи. У нас двое молчат после письма уже четыре дня, и сегодня встреча с Salon Ola. Предлагаю так: напомнить молчунам, найти двадцать новых кофеен и передать сестре три звонка. Как тебе?»

Ты отвечаешь голосом («давай без кофеен, сегодня отели»), он подстраивает план и прощается.

Цифры Джарвис берёт из твоей базы лидов в Supabase, той же, что у LEADS CONSOLE. Молчуны считаются по тому же правилу, что в консоли: статус «написал» и тишина 2+ дня.

## Как это устроено

```
GitHub Actions (по расписанию)  →  jarvis/call.mjs  →  Supabase (цифры лидов)
                                                    →  Vapi  →  звонок на твой телефон
```
Vapi — сервис, который звонит голосом ИИ. Внутри работает Claude, голос даёт ElevenLabs, распознавание речи — Deepgram. Всё это настраивается в одном аккаунте Vapi.

## Настройка (примерно 15 минут)

### 1. Vapi
1. Зарегистрируйся на https://dashboard.vapi.ai.
2. **API Keys** → скопируй **Private key**.
3. **Phone Numbers** → номер, с которого Джарвис будет звонить:
   - бесплатный номер Vapi звонит только на номера США и Канады;
   - чтобы звонить на твой номер (+48, +380, +7 и т.д.), купи номер в Twilio (twilio.com) и нажми в Vapi **Import from Twilio**.
4. Скопируй **ID** номера (это не сам номер, а его id в Vapi).

Звонки платные: Vapi берёт поминутно, точные цены на vapi.ai/pricing. Утренний звонок на 2–3 минуты стоит копейки, но баланс нужно пополнить.

### 2. Проверь у себя на ноутбуке
```bash
export VAPI_API_KEY=...          # Private key из Vapi
export VAPI_PHONE_NUMBER_ID=...  # id номера в Vapi
export MY_PHONE=+48123456789     # твой номер в формате +код страны
export SUPABASE_URL=...          # как в консоли (Settings → API)
export SUPABASE_ANON_KEY=...
export OWNER_NAME="Босс"         # как Джарвису к тебе обращаться

node jarvis/call.mjs --dry   # показать, что он скажет (без звонка)
node jarvis/call.mjs         # позвонить прямо сейчас
```
На Windows вместо `export X=...` пиши `$env:X="..."`.

### 3. Расписание: каждое утро само
В репозитории на GitHub открой **Settings → Secrets and variables → Actions**.

**Secrets** (секретные значения):
| Имя | Что |
|---|---|
| `VAPI_API_KEY` | Private key Vapi |
| `VAPI_PHONE_NUMBER_ID` | id номера в Vapi |
| `MY_PHONE` | твой номер, например `+48123456789` |
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_ANON_KEY` | anon key Supabase |

**Variables** (необязательно):
| Имя | Что | По умолчанию |
|---|---|---|
| `OWNER_NAME` | как к тебе обращаться | `босс` |
| `JARVIS_TZ` | часовой пояс для даты | `Europe/Warsaw` |
| `JARVIS_VOICE_ID` | id голоса ElevenLabs | мужской голос Adam |
| `JARVIS_NOTES` | постоянные заметки: «в пятницу созвон с сестрой» | — |

Время звонка задаётся в `.github/workflows/jarvis-morning.yml`, в строке `cron`. Время там в UTC. Сейчас стоит 07:45 по Варшаве летом, по будням.

Проверить сразу: **Actions → Jarvis morning call → Run workflow**. Телефон зазвонит через несколько секунд.

Расписание работает, только когда файлы лежат в основной ветке репозитория (main).

## Позвонить Джарвису самому
В Vapi открой **Assistants → Create**. Вставь промпт из `node jarvis/call.mjs --dry`, выбери язык `ru`, потом в **Phone Numbers** привяжи этого ассистента к номеру. Теперь, если позвонить на этот номер, ответит Джарвис. Учти: цифры в таком промпте не обновляются сами, их обновляет только утренний звонок.

## Если не работает
- `Нет переменной ...`: не задан ключ, смотри шаг 2 или 3.
- `Vapi ошибка 400`: обычно неверный номер (нужен формат `+48...`) или номер Vapi не может звонить в твою страну (нужен Twilio).
- Звонок есть, но тишина: проверь баланс в Vapi.
