КОНСОЛЬ ЛИДОВ — публикация с общей базой (ты + сестра видят одно и то же)

ШАГ 1 — Supabase (5 минут, бесплатно)
  1. supabase.com → New Project
  2. SQL Editor → вставить содержимое supabase-schema.sql → Run
  3. Settings → API → скопировать Project URL и anon public key
  4. Открыть index.html → вставить их вместо ВСТАВЬ_URL_ПРОЕКТА и ВСТАВЬ_ANON_KEY

ШАГ 2 — Vercel
  1. vercel.com → Add New → Project → перетащить ЭТУ папку
     Framework preset: Other. Build command: пусто. Output directory: ./
  2. Deploy. Получишь адрес вида console-xxxx.vercel.app
  3. Открыть с телефона → Поделиться → На экран «Домой»
  4. Ту же ссылку — сестре, тем же способом на её телефон

ШАГ 3 — защитить Google API ключ (как и раньше)
  console.cloud.google.com → Credentials → твой ключ
  · Application restrictions → HTTP referrers → добавить: https://твой-адрес.vercel.app/*
  · API restrictions → только Places API (New)
  · Billing → Budgets & alerts → лимит 5 € с уведомлением
  Ключ вводится только в твоём браузере (кнопка КЛЮЧ) — сестре сканировать не нужно,
  ей ключ не нужен вообще.

ДАННЫЕ
Теперь общие: ты сканируешь и пишешь письма, статус меняешь на «написал» —
сестра в своём телефоне видит это в реальном времени (обновление приходит само,
без перезагрузки страницы). Она звонит по скрипту, меняет статус на «ответил»,
«встреча» или «отказ» — ты видишь это у себя сразу же.

ВЫГРУЗИТЬ CSV внизу экрана — по-прежнему работает, теперь это просто бэкап
текущего состояния базы, а не единственный источник данных.

Ограничение: SUPABASE_ANON_KEY виден в исходном коде страницы любому, кто
откроет ссылку — это нормально для Supabase с политикой доступа "anon", но
значит, что саму ссылку на консоль нельзя выкладывать публично, только
передавать напрямую тем, кому доверяешь (как и раньше с адресом Vercel).
