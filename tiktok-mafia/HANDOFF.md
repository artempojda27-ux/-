# «Город засыпает» / The City Sleeps — сводка проекта

ИИ-стрим для TikTok LIVE: интерактивная «мафия» в виде фильма в стиле GTA (город как Майами).
Персонажами управляет ИИ, зрители решают исход: голосуют комментариями, влияют подарками.

## Где лежит

- Репозиторий: `github.com/artempojda27-ux/-`, ветка `claude/sleepy-ramanujan-np9fpy`, папка `tiktok-mafia/`
- Подробное описание и команды запуска: `tiktok-mafia/README.md`

## Как устроено

| часть | файл | что делает |
|---|---|---|
| движок | `traitors-engine.js` | партия: 8 из 14 персонажей, 2 мафии, шериф; ночь → утро → обсуждение → голосование → финал |
| ИИ | внутри движка | Anthropic API, модель `claude-haiku-5-5` (ключ в `ANTHROPIC_API_KEY`); `PROVIDER=mock` — без ИИ, для проверки |
| сервер | `server.js` | раздаёт сцену, шлёт события (SSE), считает голоса |
| картинка | `scene.html` | кадр 1080×1920 для OBS (Browser Source): видео, субтитры, звук |
| катсцены | `cinema.js` | подбирает видеоклипы под исход, без повторов |
| TikTok | `tiktok-bridge.js` | комментарии и подарки из реального эфира |
| тест | `emulator.js` | фейковые зрители |
| сюжет | `story.js`, `backstories.js` | допрос, повороты, финал «как это было», предыстории героев |
| голос | `tts.js` | нейроголоса Edge на сервере, у каждого героя свой |
| язык | `i18n.js`, `lang/` | `STREAM_LANG=ru` / `en` / `es` / `de` / `pt` |
| прочее | `characters.js`, `city.js`, `narrator.js`, `events.js`, `gifts.js`, `history.js` | персонажи, 16 мест города, рассказчик, события, подарки, память между партиями |

## Контент (готов, сгенерирован в Higgsfield)

- 14 персонажей: портреты в 4 состояниях (`assets/chars/`)
- 18 мест города днём и ночью + карты глубины (`assets/places/`)
- 42 катсцены (`assets/gta/clips/`): уход каждого персонажа в ночь, 10 вариантов убийцы, 7 утренних сцен, 4 варианта ареста, 2 финала, открытие с воздуха
- 42 видео реплик (`assets/gta/talk/`): каждый персонаж «говорит», «обвиняет», «оправдывается»
- Голоса: сервер синтезирует речь нейроголосами Microsoft Edge (`msedge-tts`, бесплатно, без ключа); сцена играет готовый mp3, поэтому голос слышен прямо в OBS. Нет интернета или пакета — голос браузера
- Звук синтезируется в сцене (город, дождь, сирены, сердцебиение на голосовании, удар на вскрытии роли)
- Против повторов: клипы выбираются по давности показа и каждый раз подаются по-разному (зеркало, кадр, наезд, цвет)
- Все видео в 1080p (ИИ-апскейл)
- Крючки удержания (`hooks.js`): строка-вопрос на экране, ответы персонажей зрителям по нику, предсказание ночи, улика, пауза перед вскрытием, доска детективов, тизер следующей серии

## Запуск (кратко)

```
npm install                      # один раз: голоса и мост к TikTok
STREAM_LANG=en ANTHROPIC_API_KEY=... node server.js
node tiktok-bridge.js            # подключение к эфиру TikTok
OBS → Browser Source → http://localhost:3000/scene.html, 1080×1920,
галочка «Управлять звуком через OBS»
```

Проверка без ИИ и без эфира: `PROVIDER=mock node server.js` + `node emulator.js 80`.

## Статус

Проверено (в тестовом режиме, без настоящего ИИ): полная партия от начала до конца на всех пяти языках, катсцены, видео реплик, звук, голосование на эмуляторе, доставка голоса в сцену (на заглушке вместо сервиса Microsoft).

Не проверено вживую:
1. **Нейроголоса** — из облачной среды разработки сервис Microsoft недоступен, проверить на своём ПК: при запуске сервер пишет `озвучка: нейроголоса Edge`, реплики звучат разными голосами. Если нет — `TTS=off` и вкладка-голос (README, «OBS»).
2. **Настоящий ИИ** — нужен ключ Anthropic API (≈ $0,01 за партию на Haiku 5.5).
3. **Мост к TikTok** — не тестировался на реальном эфире.

## Ответы на вопросы

1. **Где проект:** код в репозитории на GitHub (выше), всё сгенерированное лежит там же.
2. **Картинка в TikTok LIVE:** задумано через OBS (Browser Source). Stream key / LIVE Studio и доступ к LIVE у аккаунта — ещё не проверено (нужны 18+ и обычно от 1000 подписчиков).
3. **Сервисы:** ИИ — Claude Haiku 5.5 (Anthropic API); голос — нейроголоса Edge (бесплатно); работает на своём компьютере, сервер не нужен. Языки: русский, английский, испанский, немецкий, португальский; новый — пакет `lang/<код>.js`.

## Что осталось до первого эфира

1. Пробный прогон дома: `npm install`, OBS + ключ API, без выхода в эфир — проверить голоса, звук, реплики ИИ.
2. Короткий тестовый LIVE на 10–15 минут — проверить комментарии и подарки.
3. Учесть правила TikTok: в эфире пистолет и арест (может урезаться охват), контент помечать как ИИ.
